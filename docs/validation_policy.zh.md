# 模型验证

**简体中文** | [English](validation_policy.md)

按改动选择检查范围：

- 受影响的 host 测试运行一次。
- 设备执行路径变化时，每条路径选一个代表输入，通常重放 3–10 次。
- 检查权重或 KV 修改前的失败边界、输入刷新、输出归属和 BUILD/REPLAY 生命周期。
- 排查形状错误、非有限值、错误路由和缓存损坏；直接回归检查通过后结束。

使用隔离环境和匹配的运行库；确认板卡空闲并持有设备锁。完整模型/精度/长度矩阵、超过 30 次迭代、反复从零运行或自建发布验证流程，需要明确的任务要求。

<a id="数值评估"></a>
## 验收契约

运行检查覆盖 shape、dtype、有限值、输入刷新、路由归属和 KV/cache/SPM/DMA/Graph 不变量。保留资产身份、整数或结构相等，以及明确约定的确定性重放要求。

排查输出差异时，对齐权重、量化、输入、预处理和参考语义。历史通用标量门限不用于否决普通浮点舍入或累计差异；独立定义的任务要求和算子单测容差仍按各自契约执行。

记录检查所用构建、配置和输入范围。模型评估数据与报告保存在仓库外。
